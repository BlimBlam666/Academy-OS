# Crown Qualifications Build Plan

The official Crown Qualifications date and local entry rules are not yet confirmed. Ask Obsidian Gate leadership for the date, declaration deadline, required number of entries, categories, judging rubric, documentation rules, and whether related pieces may be entered separately.

Until confirmed, use **December 20, 2026** as the internal completion deadline. If the official deadline is earlier, the official date wins.

## Portfolio strategy

Finish the three core entries first. Build optional four and five only after the core set survives a mock judging.

| Priority | Entry | Proof of quality | Functional test |
|---|---|---|---|
| 1 | Soul Shard Plushie Set | Consistent pattern, clean seams, deliberate color/value, durable finish, original design notes | Toss, carry, cleaning check, ten field cycles |
| 2 | Book of Souls Foam Game Aid | Safe edges, readable silhouette, durable hinge/closure, field-visible pages or symbols | Inspection, drop test, wet-grass handling, gloved use |
| 3 | Black Root Mask | Finished inside and outside, secure fit, sight/breathing clearance, original sculpt/paint | Thirty-minute wear, movement, sweat, strap and visibility check; not protective armor |
| 4 | Black Root Field Banner | Strong composition, clean construction, readable at distance, weather-ready mounting | Wind, transport, setup, and field-distance test |
| 5 | Illuminated Reign Field Book | Original layout, legible calligraphy/illustration, documented sources, coherent Black Root visual system | A reeve can find one scenario in under 30 seconds |

Eligibility and category placement must be confirmed locally; do not assume five related pieces will count as five independent qualifying entries.

## Build gates

### Gate 1 · Requirements — September 13

- Obtain the official date, rules, rubric, categories, and submission format.
- Create a one-page design brief for each core entry: purpose, category, materials, dimensions, risks, originality, and finish standard.
- Start a build journal with dated photos before work begins.

### Gate 2 · Working prototypes — October 18

- Produce ugly-but-functional versions of all three core entries.
- Ask one crafter and one field user to test them.
- Record failures without repairing them until photographed.

### Gate 3 · Field-ready core entries — November 22

- Complete construction, safety checks, finish, and durability tests.
- Decide whether entries four and five strengthen the portfolio.
- Write a short artist statement for each piece: intent, process, challenge, and lesson.

### Gate 4 · Mock judging — December 6

- Present the entries cold to two reviewers using the known rubric.
- Score finish, function, originality, difficulty, documentation, and presentation.
- Fix the highest-impact weakness first; do not restart sound entries for minor cosmetic preferences.

### Gate 5 · Submission-ready — December 20

- Final photographs, labels, dimensions, materials, hours, costs, pattern/process notes, and safe-use statement.
- Pack each entry so it can arrive clean and undamaged.
- Keep a digital and printed copy of the portfolio.

## Weekly build rhythm

- **Tuesday:** 60–90 minute construction sprint.
- **Sunday:** Five-minute field test or reviewer check at park.
- **After each session:** One photo, time/material log, failure note, and next action.
- **Last Sunday of each month:** Portfolio review and scope cut.

## Definition of done

An entry is done when it is safe, finished from every viewing angle, tested for its intended use, photographed, documented, labeled, packed, and explainable in two minutes without apology.
